# テスト計画

[開発計画書 §13](development-plan.md#13-テスト計画)に基づく検証計画です。現在テストや実機検証の結果はありません。

## 自動テスト

実装と合わせて、次の振る舞いを検証します。

- シリアライズ、JSON Schemaと共通フィクスチャ、互換性と機能ネゴシエーション。
- 座標変換、余白・回転・リサイズ、古いキャプチャリビジョンの拒否。
- キー・ボタンの押下と解放、切断時の後始末、チャネル間の順序差。
- ペアリング、端末認証、失効、セッション状態遷移と再接続。
- 型・サイズ・範囲・対象が不正なメッセージの拒否、クリップボードの同期ループ防止。

共通の通信テストデータは[protocol/](../protocol/README.md)で管理します。

## 実機と互換性

最低対応および最新のmacOS・Android、Apple Silicon / Intel、AndroidのARM64 / ARM32、スマートフォン・タブレットを対象とします。利用可能ならRetina / 非Retina、複数ディスプレイ、異なるSoC・デコーダー、対応するx86 / x86_64エミュレーターも確認します。実機を確保できない環境では、その旨とビルド等で確認できた範囲を[互換性](compatibility.md)に記録します。

操作対象はFinder、Terminal、Visual Studio Code、Android Studio、Xcode、Safari、Google Chromeを中心とします。画面・ウインドウ取得、フォーカス、位置・サイズ変更、隠れた／最小化したウインドウ、メニュー・ダイアログ、IMEで確定した日本語・Unicode、特殊キーを確認します。H.264のハードウェア処理や音声の取り込みも実機で確認します。

## ネットワークと安全性

同一LAN、Tailscale直接接続・DERP経由、モバイル回線、回線切り替え、低速・高遅延・パケットロス、一時切断、Tailscale停止・再起動で接続と復旧を確認します。実際の通信経路を確認し、同一LAN・Tailscaleのいずれでも未登録端末からの接続を拒否できることを検証します。

期限切れ・使用済みのペアリング情報、誤ったホストの信頼情報、不正メッセージ、端末登録削除後の新規・既存接続、切断時の入力状態を確認します。

## OS状態と性能

Macのスリープ・復帰、画面ロック、ログアウト、蓋の開閉、ディスプレイ変更、対象ウインドウの変更・終了、Androidの回転・バックグラウンド・ロック、権限取り消し、ホスト終了を確認します。対応できない状態は制約として記録し、安全に接続を終了します。

性能は[開発計画書 §10](development-plan.md#10-パフォーマンス)の暫定目標を使います。操作反映遅延はAndroidでの操作から結果の画面表示までとし、端末、ネットワーク、測定方法、サンプル数、結果を記録します。長時間接続、CPU・GPU、メモリ、発熱、バッテリーも検証します。目標は保証値ではありません。
