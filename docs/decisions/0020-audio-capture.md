# ADR 0020: 音声転送

- 状態: 採用
- 日付: 2026-11-28

Macが許可した場合、ScreenCaptureKitの音声を手動レンダリングのWebRTC音声エンジンへ渡し、映像と同じ接続で送る。音声共有は初期状態でオフとし、解除時と切断時に送信を止める。再生が取得に追いつかない場合、遅延とメモリ使用量が増え続けないよう、送信待ちの音声が0.5秒を超える入力は破棄する。MacとAndroidのマイクは使用しない。受信側のWebRTCに音声再生を任せる。

API 26・37エミュレーターで合成音声と映像を受信し、API 37で送信側の音声無効化後の停止を確認した。API 37ではテスト用アプリの音声をScreenCaptureKitで取得して受信した。検証環境の音声はモノラルで、画面・ウインドウごとの取得範囲、一般アプリ、音質・遅延とAndroid実機は未検証。
