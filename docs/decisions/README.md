# 技術選定の記録（ADR）

主要な技術選定や変更について、検証結果と判断理由をここに記録します。現時点で確定済みのADRはありません。開発計画書の技術スタックや最低対応環境は検証前の候補です。

`NNNN-短い題名.md`を作成し、少なくとも以下を記載します。

```markdown
# ADR NNNN: 題名

- 状態: 提案中 / 採用 / 却下 / 廃止 / 置き換え
- 日付: YYYY-MM-DD

## 背景

## 選択肢と検証結果

## 決定と理由

## 影響・制約・未解決事項

## 関連資料
```

採用後に判断を変える場合は、元の記録を残し、後継ADRとの関係を明示します。
