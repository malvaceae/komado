# ADR 0010: 選択したディスプレイの操作

- 状態: 採用
- 日付: 2026-11-27

## 背景

画面選択は表示専用で、リモート操作はメインディスプレイに限られていた。複数画面の利用時も、認証済みの一覧から選んだ対象だけを操作できるようにする。

## 選択肢と検証結果

従来の表示要求を操作可能にすると、表示だけを意図した接続にも操作権限が付く。表示要求は維持し、選択した画面の操作を別の要求として追加する。Mac側の認証済み一覧と要求の検証、Android側の要求、原点が負のディスプレイ座標の変換を自動テストした。複数ディスプレイ実機とOSへの入力配送は未検証である。

## 決定と理由

認証済み接続でMacの機能一覧と画面一覧を取得し、一覧から選択したIDを操作要求に指定する。Macは一覧の再照合、操作許可、Accessibility権限とキャプチャ対象を確認する。入力時には選択したディスプレイの有効性と位置・サイズを確認し、キー入力はフォーカスされたウインドウの中心がそのディスプレイ内にある場合に限る。画面構成の変更時は既存の監視で接続を停止する。

## 影響・制約・未解決事項

- 新AndroidはMacが`display.control`を通知しない場合、画面選択からの操作を開始しない。従来の表示とメイン画面の操作は維持する。
- 複数画面、ミラーリング、移動・取り外し時の全ての競合、実際の入力配送、Android実機は未検証。
- 画面一覧は番号とピクセルサイズで表示するため、同じサイズの画面は区別しにくい。
