# ADR 0004: QRペアリング

- 状態: 採用
- 日付: 2026-11-27

## 背景

同一LANやVPNから接続する際に、Macの証明書フィンガープリントと期限付きペアリングコードをAndroidへ安全かつ入力しやすく渡す。接続先の手動登録は設けない。

## 選択肢と検証結果

macOSでは標準のCore ImageでQRコードを生成する。AndroidではCameraX 1.6.2でカメラを扱い、ZXing Core 3.5.4で端末内の画像を解析する。Android標準のカメラIntentにQR解析を依存すると、端末に対応アプリがあるかや結果の扱いが一定ではない。専用の外部サービスは必要としない。

Macの生成画像をVisionとAndroidのデコーダーで読み取り、Android 17エミュレーターの仮想カメラからMacへのペアリングを確認した。実際のAndroidカメラや別端末からの接続は未検証。

## 決定と理由

上記のライブラリを固定して採用し、QR画像と読み取り結果はメモリ内で扱う。認証は既存のTLS証明書照合と一回限りのコードを使う。カメラを使用できない端末では新規ペアリングできない。

## 影響・制約・未解決事項

- カメラ権限は読み取り操作時に要求し、画面終了時に解析を停止する。
- 読み取りデータの形式とサイズを検証し、画像やコードをログ・Intent・永続ストレージに保存しない。
- 実機での画質、照明、アクセス許可、画面の見た目と操作性を確認する。
- IPv6リンクローカルアドレスのゾーンは端末間で異なる場合があり、接続できるかは未検証である。
