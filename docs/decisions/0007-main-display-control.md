# ADR 0007: メイン画面の操作許可

- 状態: 採用
- 日付: 2026-11-27

## 背景

既存の画面表示を維持しつつ、認証済みAndroidからの入力を明示的に許可した場合だけMacに反映する。

## 選択肢と検証結果

従来の表示要求を操作可能に変更すると、表示だけを意図した接続にも入力権限が付く。別の要求とすることで既存の表示を維持できる。入力座標の変換、イベント生成と認証済みの映像接続は個別に検証したが、操作の実配送やロック時の挙動は未検証である。

## 決定と理由

認証後の操作要求を表示要求と分け、Macでその都度有効にする操作許可とAccessibility権限を要求する。初期対象はメインディスプレイとする。連番とキャプチャリビジョンを共有する操作メッセージを既存のReliable / Ordered DataChannelで送り、実行時にもセッションと経路を確認する。キーボードは共有画面にフォーカスされたウインドウがある場合に限る。

## 影響・制約・未解決事項

- 旧Macは操作要求に対応しない。既存の画面表示要求は変更しない。
- 操作許可はセッション終了時または待ち受け停止時に解除する。
- 画面ロックの確実な検出、フォーカス変更との競合、Macへの実配送は未検証。操作の安全性は完成していない。
- ウインドウ単位の操作、ドラッグ、スクロール、修飾キー付き操作は今後実装する。
