# ADR 0013: 映像の最大解像度

- 状態: 採用
- 日付: 2026-11-27

## 背景と決定

画面キャプチャは既定で1280×720以内に制限している。接続環境や端末によって映像の負荷を抑えられるよう、Mac側で最大解像度を標準（1280×720）または低解像度（854×480）から選ぶ。設定は保存し、次に画面またはウインドウの共有を開始するときに適用する。

実際のキャプチャサイズは縦横比を維持し、長辺と短辺をそれぞれ上限以下の偶数サイズにする。元の画面やウインドウが小さい場合は拡大しない。フレームレート、ビットレートや通信状況に応じた自動調整は変更しない。

## 検証と制約

サイズの計算、設定保存と不正設定からの既定値への復帰をテストする。低解像度のMac実画面フレームはAndroid 8エミュレーターで受信を確認した。別OS・Intel・実機やウインドウ共有での低解像度、文字の視認性、転送量や遅延は未検証。上限は一定の品質や通信量を保証するものではない。
