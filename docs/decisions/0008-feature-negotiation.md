# ADR 0008: 操作機能の確認

- 状態: 採用
- 日付: 2026-11-27

## 背景

操作メッセージを追加したAndroidが、対応していないMacへ送信すると接続が切れる。バージョンの異なる組み合わせでも、相手が対応する操作だけを送る必要がある。

## 選択肢と検証結果

アプリのバージョンだけで機能を推測する方法では、機能ごとの差や将来の追加を扱いにくい。認証済みシグナリングで明示的に一覧を取得すれば、一覧にない機能を無効化できる。形式の境界と認証後の送受信を両OSでテストし、エミュレーターの操作画面で機能確認からタップ送信まで検証した。

## 決定と理由

認証後、画面操作の開始前にMacの対応機能を取得する。Androidは必須のクリック機能がなければ操作を開始せず、ダブルクリック、ドラッグ、スクロール、文字入力と特殊キーは一覧に応じて送信・有効化する。未知の機能は無視する。一覧は接続ごとに一回だけ取得し、長さと重複を検証する。

## 影響・制約・未解決事項

- 機能一覧はアプリの実装能力を表し、認証、画面収録、AccessibilityやMac側の操作許可を代替しない。
- 一覧に対応しない旧Macへの新Androidからの操作接続は開始せず、利用者に通知する。表示のみの従来経路は維持する。
- 旧Androidは一覧を要求せず従来どおり接続する。機能ごとのバージョン、追加・廃止、詳細な互換性ルールは今後定める。
