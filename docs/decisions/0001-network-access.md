# ADR 0001: 同一LANとTailscaleからの接続

- 状態: 採用
- 日付: 2026-11-27

## 背景

当初はシグナリングとWebRTCをTailscale経由に限定する計画だった。macOSで候補ライブラリのアダプター種別による制限を試したところ、Tailscale以外のICE候補も残った。

## 決定と理由

同一LANでは直接接続し、外出先からは既存のTailscale環境を使えるようにする。Tailscaleは必須にせず、アプリ専用のVPNや中継サービスも設けない。これにより同一LANでも自然に利用でき、Tailscaleのみへの経路制限を製品要件にしない。

## 影響・制約・未解決事項

- どの経路でもペアリング、端末認証、シグナリングのTLS、WebRTCの暗号化を適用する。LANやTailscaleの接続自体を端末認証の代わりにしない。
- シグナリングサーバーをインターネットに公開しない方針は維持する。具体的な待ち受け範囲とアクセス制御は設計・検証が必要。
- SDPを交換する認証済みの相手とWebRTCのDTLS接続先を結び付ける方式を設計・検証する。
- 同一LANとTailscaleの両経路で動作を検証する。Tailscaleの接続状況によりDERPを経由することがある。
