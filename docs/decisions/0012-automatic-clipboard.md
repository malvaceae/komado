# ADR 0012: クリップボード自動同期

- 状態: 採用
- 日付: 2026-11-27

## 背景と決定

手動共有に加え、使用中に両端のテキストを同期する。意図しない既存データの転送を避けるため、Macの操作許可と共有許可に加え、MacとAndroidそれぞれの自動同期の許可を必要とする。既定では無効とし、開始時には双方の変更の基準だけを記録する。Androidのフォーカス喪失で停止し、復帰時には基準を取り直す。

転送は認証・暗号化された操作チャネルを使用し、手動共有と同じテキスト・サイズ・期限・連番の制約に従う。Androidからの送信前にはMacの許可を準備要求で確認する。受信内容の再送を防ぎ、Androidで要求中に新しいコピーがあればMacからの応答で上書きしない。

MacではConcealed、Transient、AutoGenerated、1Password、リモート由来の既知のペーストボード形式を除外する。Androidでは機密やリモート由来の印を除外し、新しいOSで公開されているリモート共有除外のフラグも利用可能なら確認する。Android 37.2以降の公開APIは実行環境で有無を確認し、旧OSでも動作させる。

## 制約

機密情報に印を付けないアプリもあるため、自動同期で転送されないとは保証できない。Androidのコピー時刻は同じミリ秒の変更を区別できず、通知・読み取り・書き込み間の競合も残る。画像やファイルは対象外。Android 37.2エミュレーターでは公開APIによるリモート共有除外の指定を確認した。実機、一般のアプリ、ロック状態、新APIのリモート由来判定は未検証。
