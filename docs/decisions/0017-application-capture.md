# ADR 0017: アプリ単位の表示と操作

- 状態: 採用
- 日付: 2026-11-28

## 背景

一つのアプリの複数ウインドウを表示し、対象を切り替えずに操作する。別アプリへの誤入力は避ける。

## 選択肢と検証結果

ScreenCaptureKitの[アプリ指定フィルター](https://developer.apple.com/documentation/screencapturekit/sccontentfilter/init%28display%3Aincluding%3Aexceptingwindows%3A%29)は、指定アプリのウインドウを一つのディスプレイ上で取得する。別プロセスのテストアプリの2ウインドウがAndroidに表示され、アプリへの入力が届くことと、手前の別アプリへの入力が拒否されることを確認した。

## 決定と理由

認証後にScreenCaptureKitのアプリ一覧をページ単位で送り、アイコンはAndroidが表示する候補から必要に応じて取得する。開始時は送信済みのプロセスIDとバンドル識別子を再照合する。アプリの画面上のウインドウを含むディスプレイを選び、なければメイン画面を使う。入力時はAccessibilityの入力先とウインドウ情報を使い、対象アプリのウインドウを照合する。

## 影響・制約・未解決事項

取得対象は一つのディスプレイで、別の画面にあるウインドウは表示されない。アプリ終了やプロセスIDの再利用などの競合を完全には防げない。アイコンが取得できないアプリは標準の代替アイコンを表示する。アプリ外に生成されるメニュー・ダイアログや一般アプリ、実機、複数ディスプレイは未検証である。
