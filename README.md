# komado

Android端末からMacのデスクトップや個別のウインドウを操作する、ネイティブのリモートデスクトップアプリケーションです。同一LAN内の直接接続と既存のTailscale環境を利用した接続に対応し、映像・音声・操作イベントにはWebRTCを利用する計画です。

現在はQRコードまたは手動でのペアリングとMacのディスプレイ・ウインドウの選択と表示を初期実装しています。選択した画面と個別ウインドウへのクリック・ドラッグ・スクロール、文字・キー入力とトラックパッド操作を初期実装しています。ウインドウの操作はMac上で見えている部分に限られ、実際の操作や画面ロック時の安全な停止は未検証です。音声転送は未実装で、複数ディスプレイ、他アプリのウインドウ、Android実機やTailscale経由の動作も未検証です。

**現在はPhase 0の技術検証と基礎実装の段階です。製品版アプリケーションと配布物はまだありません。** 対応環境、ライブラリ、通信方式の詳細は技術検証後に確定します。
