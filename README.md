# komado

Android端末からMacのデスクトップや個別のウインドウを操作する、ネイティブのリモートデスクトップアプリケーションです。既存のTailscale環境を利用し、映像・音声・操作イベントにはWebRTCを利用する計画です。

**現在はPhase 0の技術検証段階です。製品版アプリケーションと配布物はまだありません。** 対応環境、ライブラリ、通信方式の詳細は技術検証後に確定します。
