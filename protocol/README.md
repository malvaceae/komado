# プロトコル資産

macOSとAndroidで共有する通信仕様の資産を管理する場所です。初期認証とSDP交換、キャプチャ開始通知、クリック、確定文字列の形式を`schemas/`に定義し、両OSで使うテストデータを`fixtures/`に置いています。クリックのDataChannel送受信は検証用に接続していますが、アプリのタップや入力APIには未接続です。確定文字列は形式と検証のみです。[通信プロトコルの設計案](../docs/protocol.md)と[開発計画書 §8](../docs/development-plan.md#8-通信設計)を参照してください。

仕様が定まった範囲から、シグナリングと操作メッセージのJSON Schemaを`schemas/`に、両実装で使う正常・異常系のテストデータを`fixtures/`に追加します。`device-auth-valid.json`はテスト用の公開鍵と署名のみを含み、実端末の認証情報は含みません。メッセージの変更時は互換性、双方の実装とテスト、ドキュメントを確認します。アプリとプロトコルのバージョンは別に管理します。
